# Cosmic Shooter

HTML/CSS/JavaScriptだけで作った、縦スクロールのミニシューティングゲームです。
宇宙船を操作して、画面上から迫ってくる隕石や敵機をレーザーで撃ち落とします。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「スタート」を押します。
3. ← / → キー、または A / D キーで宇宙船を左右に動かします。
4. スペースキーでレーザーを発射します。
5. 45秒間、隕石や敵機を撃ち落としてスコアを伸ばします。敵にぶつかってライフが0になるとゲームオーバーです。

## ローカルで起動する例

```bash
python3 -m http.server 4173
```

その後、ブラウザで `http://127.0.0.1:4173/` を開いてください。
